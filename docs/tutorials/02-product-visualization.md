# Video Tutorial: Product Visualization with AI

## Duration: 8 minutes

## Script

### Intro (0:00 - 0:30)
"Let's create a professional product visualization using AI and blender-mcp-ultra."

### Scene Setup (0:30 - 2:00)
1. Create product mesh
2. Add subdivision surface modifier
3. Create PBR material (metallic, roughness)
4. Assign material to product

### Lighting Setup (2:00 - 3:30)
1. Three-point lighting setup
2. Adjust key light intensity
3. Add fill light for shadows
4. Add rim light for separation

### Camera Setup (3:30 - 4:30)
1. Create camera with 85mm lens
2. Position camera for product shot
3. Enable depth of field
4. Set focus on product

### Environment (4:30 - 5:30)
1. Add HDRI environment
2. Adjust world settings
3. Add floor plane
4. Apply floor material

### Render Settings (5:30 - 6:30)
1. Set render engine to Cycles
2. Configure samples (128-256)
3. Enable denoising
4. Set resolution (1920x1080)

### Final Render (6:30 - 7:30)
1. Preview render
2. Adjust lighting
3. Final render
4. Show result

### Outro (7:30 - 8:00)
"You've created a professional product visualization using AI! Try different materials and lighting setups."
